# REST por fatia vertical
Inspecione o router e autenticação existentes. Especifique OpenAPI antes de expor endpoint; padronize JSON, status HTTP, erros, paginação, filtros e autorização por tenant. Escreva testes de contrato, autorização e isolamento. Não criar endpoint sem serviço de domínio e testes.
