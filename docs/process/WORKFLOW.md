# Workflow Claude Code
1. Inspecionar repo, git status, testes e ferramentas; não executar mudanças ainda.
2. Selecionar spec por dependência e criar plano de implementação com riscos.
3. Identificar lacunas da auditoria e propor regras próprias com ADR quando necessário.
4. Implementar migração/modelo/serviço/rota/UI/autorizações em fatia vertical.
5. Criar testes unitários, integração, autorização, contrato e E2E com dados sintéticos.
6. Executar linters, testes e análise estática disponíveis; registrar comandos e resultados.
7. Revisão de segurança, UX e acessibilidade; atualizar spec e cobertura.
8. Commit pequeno somente se autorizado; nunca publicar automaticamente.
9. Repetir até completar backlog; não ignorar falhas para avançar.
