# Segurança obrigatória
Autenticação robusta, 2FA quando suportado, gestão de sessão, CSRF, escaping, validação server-side, consultas parametrizadas, rate limiting, RBAC/ABAC e deny-by-default.
Testar IDOR, elevação de privilégios, vazamento entre condomínios, exportação não autorizada, upload malicioso, XSS, SQL injection, SSRF e concorrência financeira.
Segredos fora do repositório; backups criptografados e testados; logs sem dados pessoais excessivos; retenção, minimização, base legal e direitos LGPD.
Nenhum teste ofensivo contra APControle: testes apenas no ambiente próprio autorizado.
