# Política de evidências
- CONFIRMADA: somente o que o PDF efetivamente registra como observado; uma rota confirmada não confirma seus campos internos.
- INFERIDA: hipótese de modelo ou fluxo; exige teste próprio e decisão documentada.
- PENDENTE: falta de evidência; nunca preencher com comportamento fictício do APControle.
- REQUISITO_PROPOSTO: escolha de projeto para Connect ERP, não afirmação sobre APControle.
Toda spec registra origem, página do PDF, status, dependências e dúvidas.
Páginas AP-097 (Logs), Usuários do Sistema e Permissões de Usuários estavam pendentes na fonte.
