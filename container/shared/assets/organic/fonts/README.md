# Fontes Organic

A família tipográfica é **Montserrat** (SIL Open Font License 1.1, texto em `Montserrat-OFL.txt`), servida daqui
mesmo, sem Google Fonts: `Montserrat-latin.woff2` e `Montserrat-latin-ext.woff2` (fonte variável, pesos 400 a 700).

Até 22/11/2026 era a **Gotham**, que é paga e não tinha licença de uso na web comprovada; os arquivos saíram do
repositório (ADR 0604, etapa 3). Se o pacote Organic for sincronizado de novo (`service/commands/sync-organic-v2.php`),
confira que o `organic.css` e o `organic.min.css` continuam apontando para a Montserrat.

A camada de compatibilidade **Organic Icons** usa a fonte de ícones histórica do Studio: `studio.eot`, `studio.woff`,
`studio.ttf` e `studio.svg`.
