A Connect administra vários condomínios. Para você não misturar dados de um com os de outro, o sistema trabalha sempre **no condomínio escolhido na barra superior**.

## Onde fica

No alto de qualquer tela, ao lado do título, fica o campo **Condomínio**.

```tela condominio-seletor
rota: /dashboard
condominio: residencial-jardim-das-acacias
legenda: Seletor de condomínio na barra superior
1: .erp-condo-switch | Condomínio em que você está trabalhando
2: main h1 | A tela mostra os dados só desse condomínio
```

## Como trocar de condomínio

1. Clique no campo **Condomínio**.
2. Escolha o condomínio na lista. Só aparecem os condomínios vinculados à sua conta.
3. A tela recarrega com os dados do condomínio escolhido. O nome dele também aparece no endereço da página, então você pode salvar o link nos favoritos.

> O sistema lembra o último condomínio escolhido. Ao entrar de novo, você continua de onde parou.

## Ver todos os condomínios

Escolha **Todos os condomínios** no mesmo campo. O [Dashboard](artigo:dashboard) passa a mostrar o resumo da carteira inteira.

Algumas telas só funcionam com um condomínio escolhido, como cadastrar uma unidade ou emitir uma fatura. Nesse caso o sistema mostra o aviso **Escolha um condomínio** e espera você selecionar um na barra superior.

>! Antes de gravar, confira o nome do condomínio na barra superior. Tudo o que você cadastrar entra no condomínio que estiver selecionado.
